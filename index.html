💬 แชทแผนก

KBS · ห้องสนทนารวม
ยังไม่ได้เชื่อมต่อ Firebase

คู่มือเปิดใช้งานแชท
  1. เข้า Firebase Console สร้างโปรเจกต์ แล้วเพิ่มแอป Web (</>) ไม่ต้องเปิด Firebase Hosting
  2. สร้าง Realtime Database ในโหมด Locked แล้วคัดลอก databaseURL เปิด Authentication → Sign-in method → Email/Password
  3. ใน Project settings → Your apps คัดลอกค่าจาก firebaseConfig มาใส่ JSON ในไฟล์ HTML ตรง kbs-chat-config (apiKey, authDomain, databaseURL, projectId, appId) ต้องใช้เครื่องหมายคำพูดคู่ JSON และไม่ใส่ const หรือเครื่องหมาย ;
  4. Authentication → Settings → Authorized domains เพิ่มโดเมน GitHub Pages เช่น pjaomsins-stack.github.io (ไม่มี https หรือเส้นทาง)
  5. Authentication → Users → Add user สร้างบัญชีพนักงานแต่ละคน แล้วคัดลอก UID ของแต่ละบัญชี
  6. Realtime Database → Data เพิ่ม chatMembers/UID/name เป็นชื่อพนักงาน เช่น “ออมสิน” เปลี่ยน UID ให้ตรงกับบัญชีจริง ต้องเพิ่มสมาชิกก่อนจึงอ่านหรือส่งข้อความได้ รหัสผ่านเก็บใน Authentication เท่านั้น
  7. Realtime Database → Rules วางกฎด้านล่างแล้ว Publish (หากมีข้อมูลระบบอื่นอยู่แล้ว ให้รวมกฎอย่างระมัดระวัง)


บันทึกไฟล์เป็น index.html แล้วอัปโหลดแทนไฟล์เดิมใน GitHub เว็บแชทแสดง 100 ข้อความล่าสุด โดยข้อความเก่ายังอยู่ในฐานข้อมูล
ทดสอบเปิดเว็บจากสองเครื่อง ล็อกอินคนละบัญชี แล้วส่งข้อความไป–กลับ ทดสอบบัญชีที่ไม่มีใน chatMembers ว่าเข้าไม่ได้ด้วย
การลบสมาชิกออกจาก chatMembers จะตัดสิทธิ์แชท หน้าเว็บและรายงานเดิมยังใช้สิทธิ์แบบเดิม กฎนี้ป้องกันเฉพาะข้อมูลแชท ควรติดตามปริมาณใช้งานและโควตาใน Firebase
